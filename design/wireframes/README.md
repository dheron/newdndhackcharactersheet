# Wireframes

Source files for the approved character sheet wireframes, copied from the design canvas (https://claude.ai/artifact/UxYwW4xMuRj5HTswjeK2ca, private to David).

They are Design Component files (`.dc.html`) and need the canvas runtime to render; open the canvas to view them. They are kept here as the layout reference for the real build. See `docs/character-sheet-spec.md` for the written spec.

- `page1-print.dc.html`: page 1, all classes, US Letter.
- `page2-<class>.dc.html`: page 2 for each spellcasting class.
